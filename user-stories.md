# Smart Clinic Management System — User Stories

## 1. Admin
- As an admin, I want to manage doctors so that doctor information stays updated.
- As an admin, I want to view patients so that I can manage clinic records.
- As an admin, I want to view appointments so that I can monitor clinic activities.

## 2. Doctor
- As a doctor, I want to view my appointments so that I can manage my schedule.
- As a doctor, I want to view patient details so that I can provide appropriate care.
- As a doctor, I want to create prescriptions so that patients can follow their treatment.

## 3. Patient
- As a patient, I want to log in so that I can access my clinic information.
- As a patient, I want to view doctors by specialty so that I can find the right doctor.
- As a patient, I want to book appointments so that I can consult a doctor.
- As a patient, I want to view my appointments so that I can track their status.

## 4. System
- The system should store patient, doctor, and appointment details in a database.
- The system should provide APIs to retrieve and manage clinic information.
- The system should protect patient information and restrict access to authorized users.
